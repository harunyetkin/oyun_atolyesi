# Oyun Atölyesi

Oyunları kod yazmadan, ayar panelleriyle tasarlayıp anında oynayabileceğin masaüstü aracı.
Fikir ve yön: **Harun**. Kodlama, tasarım ve test: **Claude**.

## İlk kurulum (bir kerelik)
1. **GitHub Desktop**'ta **File → Clone repository** → `harunyetkin/oyun_atolyesi` → **Clone**.
2. Bilgisayarındaki depo klasörünü aç (GitHub Desktop'ta **Repository → Show in Explorer**).
3. **`exe_yap.bat`** dosyasına çift tıkla. 1–2 dakika sürer; sonunda klasörde
   **`OyunAtolyesi.exe`** oluşur.
4. `OyunAtolyesi.exe`'ye çift tıkla.

## Güncellemeleri almak
GitHub Desktop'ta **Fetch origin** → **Pull origin**, sonra `exe_yap.bat`'ı tekrar çalıştır.

## Projelerin nerede?
`Belgeler\OyunAtolyesi\projeler` — her oyun bir klasör. Dışa aktarılan oyunlar
`Belgeler\OyunAtolyesi\disari` altında, çift tıklayınca tarayıcıda açılan tek bir dosya olarak durur.
